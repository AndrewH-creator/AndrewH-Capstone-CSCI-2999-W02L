Hissong Technology Services
Small Business Security Assessment and Incident Response Lab

Author: Andrew Hissong
Institution: Columbus State Community College
Project Phase: Phase 1

Project Overview

This project simulates a cybersecurity assessment of a fictional small business called Hissong Technology Services. It demonstrates asset identification, risk assessment, network documentation, security recommendations, and incident response planning.

Objectives
Identify important business assets.
Document a proposed small-business network.
Identify potential threats and security risks.
Calculate preliminary risk scores.
Recommend security controls.
Establish a foundation for future incident-response exercises.
Tools
Python
GitHub
Microsoft Word and Excel
Mermaid diagram editor
Additional lab tools such as Linux, Nmap, and Wireshark as they become available and are used in authorized exercises.
Requirements

Python 3.10 or newer. The Phase 1 Python script uses standard Python libraries and does not require third-party packages.

How to Run

Open a terminal in the directory containing main.py and run:

python main.py


If your environment uses the python3 command, run:

python3 main.py

Generated Files

The program generates an output folder containing:

security_assessment_report.md
asset_inventory.csv
risk_register.csv
network_diagram.mmd
assessment_summary.json
README.md
Risk Assessment Method

Likelihood and impact are each scored from 1 to 5. The risk score is calculated by multiplying likelihood by impact. Ratings are preliminary estimates for a fictional business.

Safety and Limitations

The business, assets, and risk scenarios are fictional. The Phase 1 script does not scan networks or confirm vulnerabilities. Any future technical testing will be performed only against systems for which authorization has been obtained.

Future Phases

Planned activities include controlled lab testing, simulated incident creation, log analysis, packet-capture examination, incident timelines, and recommendations based on collected evidence.

Research

Research sources will be documented in the project's research deliverable and updated as the project develops.
